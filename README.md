# Sugar-Cube-Variable-Editor
Tool made for testing and bug fixing for games or other html based software that uses SugarCube for variable storage. To use, just copy tool.txt and paste into console.


# Features

works with SugarCube2.x and any Twine game running SugarCube API

auto variable group sort based on name (enemy_health, enemy_dmg, enemy_name)

Has the ability to minimize, remove and refresh



written in JS
